# Публичный рейтинг (apps.leaderboard)

Публичный сайт «OkurmenKIDS Leaderboard»: топ студентов и топ групп за **год**,
**месяц** и **неделю**. Без регистрации, только чтение.

## Откуда берутся XP

В проекте не было XP. Отдельная таблица начислений не заводится: XP
**вычисляются** из уже существующих датированных записей журнала, поэтому
исторические периоды считаются по реальным данным, ничего не выдумывается, а
исправление или удаление записи сразу меняет рейтинг.

| Источник | Правило | Дата события | Защита от двойного начисления |
|---|---|---|---|
| `academy.Attendance` | PRESENT = 10 XP, LATE = 5 XP; ABSENT/EXCUSED = 0 | дата занятия | уникальна на (студент, занятие) |
| `academy.HomeworkResult` | SUBMITTED/CHECKED = 10 XP, LATE = 5 XP, + оценка тренера (0–10, не больше 10) | дата занятия, на котором задано ДЗ | уникален на (ДЗ, студент) |
| `testing.StudentAttempt` (FINISHED, студент LMS) | лучшая попытка в сессии теста: round(балл / 5) = 0–20 XP | локальная дата завершения лучшей попытки | одна сессия = одно начисление; пересдача в другом периоде ничего не добавляет |

Отменённые занятия (`Lesson.status = cancelled`) не дают XP.

## Периоды

* Год — 1 января … 31 декабря; месяц — 1-е … последний день; неделя —
  понедельник … воскресенье (`week_start` обязан быть понедельником).
* Календарь проекта — `settings.TIME_ZONE` (Asia/Bishkek); время попыток
  тестов переводится в него, поэтому граница периода не сдвигается из-за UTC.
* Будущие периоды отклоняются (400). Изменение позиции сравнивается только
  с предыдущим периодом того же типа (прошлый год / месяц / неделя).

## Кто в рейтинге

Активные студенты (`Student.is_active`) открытых групп (active / paused) с
XP > 0 за период. Новое поле `Student.show_in_leaderboard` (миграция
`academy/0025`, по умолчанию «да», меняется в админке студента) —
приватность: при выключении студент остаётся на своём месте анонимной строкой
«Скрытый участник» без имени и группы; его XP учитываются в группе.

Одинаковые XP — одно место (1, 2, 2, 4). Позиция всегда общая по академии,
даже при фильтре или поиске.

Изменение позиции: `up`/`down`/`same` с разницей мест, `new` — студента не
было в рейтинге прошлого периода, `null` — в прошлом периоде нет данных вообще
(нейтральное состояние, динамика не выдумывается).

## Рейтинг групп

Группы сравниваются по **среднему XP на студента** = сумма XP текущих
участвующих студентов группы за период ÷ их число (включая студентов без XP).
Сумма XP показывается справочно. Группы без XP за период не ранжируются.

## API (GET, без авторизации)

```
GET /api/v1/public/leaderboard/meta/
GET /api/v1/public/leaderboard/students/?period=year&year=2026
GET /api/v1/public/leaderboard/students/?period=month&year=2026&month=10
GET /api/v1/public/leaderboard/students/?period=week&week_start=2026-10-12
      &q=<имя> &group=<ключ> &course=<ключ> &order=desc|asc &page=1 &page_size=20 (≤100)
GET /api/v1/public/leaderboard/groups/?period=…&q=&course=&order=&page=&page_size=
```

Ответ — закрытый список полей: публичное имя (имя + первая буква фамилии),
инициалы, непрозрачные ключи (HMAC от id и SECRET_KEY, как у публичного
расписания), названия группы и направления, XP и их разбивка. Без телефонов,
id из базы, статусов, комментариев и оценок отдельных работ. POST/PUT/PATCH/
DELETE → 405. Лимит запросов на IP — `PUBLIC_LEADERBOARD_RATE` (1200/hour).

## Кэш

Полный рейтинг периода кэшируется на `PUBLIC_LEADERBOARD_CACHE_SECONDS`
(120 с). Версия кэша сбрасывается сигналами при сохранении/удалении
Attendance, HomeworkResult, Homework, Lesson, Student, Group, Course и
завершённых попыток тестов; массовые `.update()` покрывает короткий TTL.

## Сайт

Фронтенд — `frontend/src/features/leaderboardSite`, адреса `/leaderboard`
(топ студентов) и `/leaderboard/groups`. Отдельный домен: тот же фронтенд с
`VITE_APP_MODE=leaderboard`; на бэкенде добавьте домен в
`LEADERBOARD_SITE_ORIGINS` (CORS).

## Тестирование

### Автотесты

```bash
# backend — расчёт XP, периоды, часовой пояс, группы, приватность, API, демо-команда
cd backend && DJANGO_ENV=testing python manage.py test apps.leaderboard

# frontend — страницы /leaderboard и /leaderboard/groups (API замокан)
cd frontend && npx vitest run src/features/leaderboardSite
npm run build   # production-сборка
```

### Вручную на демо-данных

```bash
cd backend
python manage.py migrate
python manage.py seed_leaderboard_demo        # 6 групп «[DEMO-LB] …», 39 студентов, данные с 1 января прошлого года по сегодня
python manage.py runserver                    # API на :8000

cd frontend && npm run dev                    # http://localhost:5173/leaderboard
```

Команда работает только вне production (`DJANGO_ENV=production` — отказ),
при повторном запуске пересоздаёт демо-данные, а
`python manage.py seed_leaderboard_demo --clear` удаляет только их (группы,
курсы и тест с пометкой «[DEMO-LB]» и их студентов) — реальные данные не
затрагиваются.

Что проверить:

| Что | Где / как | Ожидается |
|---|---|---|
| Период | Год / Месяц / Неделя, стрелки недели, выбор месяца и года | пьедестал, таблица, число участников и даты периода меняются; будущие периоды недоступны |
| Динамика | месяц или неделя | ▲ / ▼ / — 0; последний студент группы «Python Start» появился на этой неделе → NEW |
| Приватность | рейтинг за год | одна строка «Скрытый участник» без имени и группы |
| Поиск и фильтры | поиск по имени, «Направление», «Группа», кнопка XP | список сужается, места остаются общими; «Показать ещё» догружает |
| Топ групп | `/leaderboard/groups`, клик по группе | ранжирование по среднему XP на студента; раскрывается список студентов группы |
| Исправление результата | в админке поменять отметку посещаемости демо-студента | рейтинг меняется при следующем запросе (кэш сбрасывается) |
| Ошибки | остановить backend и обновить страницу | сообщение «Не удалось загрузить рейтинг» и кнопка «Повторить» |
| Адаптивность | 1440 / 1024 / 768 / 390 px (DevTools) | без горизонтальной прокрутки, на телефоне карточки вместо таблицы |

Проверка API напрямую:

```bash
curl "http://localhost:8000/api/v1/public/leaderboard/meta/"
curl "http://localhost:8000/api/v1/public/leaderboard/students/?period=month&year=2026&month=10&page_size=5"
curl "http://localhost:8000/api/v1/public/leaderboard/groups/?period=week&week_start=2026-10-12"
curl -X POST "http://localhost:8000/api/v1/public/leaderboard/students/"   # → 405, только чтение
```
