# Полный сброс бухгалтерии Jasmina Karimberdieva — инструкция

Выполняет **активный суперпользователь Django**. Учебные данные (ученица,
зачисление, группа, программа, расписание, уроки, посещаемость, тесты и
экзамены, тренеры) не удаляются и не меняются — операция сверяет это сама
и при любом расхождении отменяет всё.

## 0. Перед началом

1. Сделайте резервную копию базы (`pg_dump -Fc …`). Копия удаляемых строк
   также сохраняется в журнал аудита, но полная копия базы — обязательна.
2. Сверьте с кассой / банковской выпиской платежи №41, №42, №148, №149 по
   19 000 сом (проведено 76 000 при договоре 38 000):
   * №39 (38 000, 19.08) сторнирован, №41 + №42 внесены **взамен него** —
     это те же 38 000;
   * №148 + №149 — та же разбивка, внесённая повторно.

   Запишите, какие деньги **реально** получены и когда, — после сброса их
   нужно внести в новый профиль (шаг 3). Если по вашим правилам эти
   платёжные документы обязаны храниться — полный сброс не выполняйте.
3. Подготовьте подтверждённые условия договора: программа Prog SOFT 3,
   стандартная стоимость 60 000, итоговая 38 000 (скидка 22 000), помесячная
   оплата, 4 учебных месяца × 12 IT-уроков, дата начала по договору.

## 1. Отчёт (ничего не меняет)

Django Admin → **Оплата обучения → Платёжные профили студентов** → найдите
«Karimberdieva» → отметьте её профиль → действие **«Удалить профиль из
бухгалтерии»** → «Выполнить».

Проверьте на странице:
* список типов записей и количества — только бухгалтерские модели;
* таблицу «проведённые платежи» — №41, №42, №148, №149, итого 76 000,
  отметки «возможен повторный ввод», закрытые периоды (если есть);
* блок «связи с другими записями» должен отсутствовать (если он есть —
  сброс невозможен, исправьте связи в «Неправильные данные»).

## 2. Полный сброс

В блоке **«Полный сброс бухгалтерии ученика»** заполните:
* причину (например: «Ошибочный учёт; начинаем заново по договору от …»);
* фамилию: `Karimberdieva`;
* фразу: `СБРОСИТЬ БУХГАЛТЕРИЮ`;
* отметку «Понимаю: проведённые платежи и чеки будут удалены…»;
* при закрытом периоде — отметку о периоде.

Нажмите **«Полностью сбросить бухгалтерию»**. Если с момента открытия
отчёта что-то изменилось (например, внесён новый платёж), удаление не
выполнится — откройте отчёт заново.

Результат: профиль исчез из списка; в журнале аудита (Бухгалтерия → Журнал
аудита, действие `billing_profile_purge`) — кто, когда, причина, список
удалённых платежей и чеков и полная копия всех удалённых строк.

## 3. Новый профиль с чистого листа

Создайте профиль обычным способом (страница «Студенты / подключение к
оплате»): ученица Jasmina Karimberdieva, тариф **Prog SOFT 3**, дата начала
по договору, «Скидка предоставлена», итоговая стоимость **38 000**, способ
оплаты **помесячно**. Первый учебный месяц и его начисление создаются по
обычным правилам; уроки с даты начала спишутся в новый профиль автоматически,
каждый — один раз.

Затем внесите **реально полученные** деньги обычной оплатой с настоящей
датой поступления (по итогам сверки из шага 0) — новые чеки выдаются
автоматически.

## 4. Проверка

* Карточка ученицы в оплате: стоимость 38 000, получено — только внесённое
  на шаге 3, долг и аванс по новому договору.
* «Учебные месяцы»: 4 × 12 уроков, уроки не задвоены.
* Ученица, группа, расписание, посещаемость — без изменений.
