# Отчёты для родителей (`apps.reports`)

Группа → KPI → **Отчёты** → «Создать отчёт»: картинка OkurmenKIDS (PNG, 1600×1100)
и текст для WhatsApp по реальным данным LMS. Без внешних AI-сервисов и API-ключей:
статистика — Django ORM, рекомендации — правила на Python, текст — шаблоны,
изображение — Django-шаблон + локальный headless Chromium (Playwright).

## Откуда берутся цифры

Расчёт — `services/analytics.py`, на движке «Прогресса студентов» группы
(`apps.academy.services.analytics.student_progress`), поэтому отчёт совпадает с вкладкой KPI.

| Показатель | Правило |
|---|---|
| Студенты отчёта | активные студенты группы **на последний день периода** (`student_roster`): деактивированные, на паузе, выпущенные и переведённые в другую группу не попадают ни в таблицу, ни в итоги группы |
| Проведённые занятия | статус «Проведён» и дата ≤ сегодня; отменённые и будущие не считаются |
| Запланированные | все занятия периода, кроме отменённых |
| Посещаемость | (присутствовал + опоздал) / отмеченные занятия; неотмеченное занятие — не пропуск |
| Домашние задания | сдано / выданные ДЗ проведённых занятий; нет ДЗ — «Нет данных» |
| Средний балл | среднее всех выставленных оценок (0–10); пустая оценка — не ноль |
| Тесты | завершённые попытки студентов группы за период; попытки, ждущие проверки, не учитываются |
| Тренер | считает только свои занятия (изоляция тренеров в общей группе) |

Нет данных → `null` / «Нет данных» (кырг. «Маалымат жок»), никогда не 0%.

**Сравнение** — с равноценным прошлым периодом (месяц ↔ прошлый месяц с тем же числом дней,
неделя ↔ прошлая неделя, произвольный/7 дней ↔ столько же дней до него), для **тех же студентов**.
Сравниваются только доли и средние, не количества.

**Статус студента**: среднее доступных показателей (посещаемость, ДЗ, балл×10, тесты):
≥85 «Отлично», ≥70 «Хорошо», ≥55 «Нужно внимание», иначе «Требуется поддержка»;
посещаемость <50% — всегда «Требуется поддержка».

## Рекомендации

`services/recommendations.py` — список правил `Rule(section, условие, ru, ky)`. Правило
срабатывает только если у показателя есть данные. Три раздела: «Сильные стороны»,
«На что стоит обратить внимание», «Рекомендации родителям»; пустой раздел получает
нейтральную правдивую фразу. Пороги: посещаемость <70 / ≥95, ДЗ <60, балл ≥9 / <5, тесты <60 и т.д.

## API

| Метод | URL | |
|---|---|---|
| GET | `/api/v1/groups/{id}/parent-reports/preview/` | расчёт + тексты, ничего не сохраняется |
| POST | `/api/v1/groups/{id}/parent-reports/generate/` | новый отчёт в истории (PNG + текст) |
| GET | `/api/v1/parent-reports/` | история (`?group=`, `?report_type=`) |
| GET | `/api/v1/parent-reports/{id}/` | детали: снимок расчёта, тексты, рекомендации |
| GET | `/api/v1/parent-reports/{id}/download/` | PNG (`?image=`), без параметра — PNG или ZIP всех страниц |
| POST | `/api/v1/parent-reports/{id}/regenerate/` | пересчёт тех же дат — **новый** отчёт, старый не меняется |
| POST | `/api/v1/parent-reports/{id}/text/` | `{text}` — сохранить правку, `{reset: true}` — вернуть, `{language}` — текст на другом языке |

Параметры генерации: `period` (`today`, `last_7_days`, `this_week`, `last_week`, `this_month`,
`last_month`, `custom` + `start_date`/`end_date`), `report_type` (`group` / `students`),
`language` (`ru` / `ky`), `output_format` (`png` / `text` / `both`), `include_table`,
`include_group_stats`, `include_recommendations`, `include_comparison`, `student_ids`.
Все даты и ID проверяются на сервере; значения KPI от клиента не принимаются.

## Доступ

* Администратор — все группы. Руководитель тренеров — просмотр, история и скачивание, без генерации.
* Тренер — только свои группы и только свои занятия; в истории — только отчёты по своим занятиям.
* Ассистент, директор, бухгалтер — нет доступа (у них нет доступа к KPI в LMS).

PNG хранятся в `MEDIA_ROOT/private/parent_reports/` — публичной ссылки нет, только скачивание через API.

## Изображение

`templates/reports/group_report.html`, `student_report.html`. Логотип и шрифт DejaVu
встраиваются как data-URI, браузер не выходит в сеть. Большая группа разбивается на
несколько страниц (`services/layout.py`), размер текста не уменьшается; таблица не
разрывается, если помещается на одну страницу. После рендера проверяется, что ничего
не обрезано (предупреждение в логе).

Если Chromium недоступен, отчёт всё равно сохраняется (статус «Готов без изображения»,
причина в `error`) — текст можно скопировать, PNG — перегенерировать позже.

## Установка

```bash
pip install -r requirements.txt
python -m playwright install --with-deps chromium
python manage.py migrate parent_reports
```

В Docker это делает `Dockerfile` (`PLAYWRIGHT_BROWSERS_PATH=/ms-playwright`). Системный
Chromium можно указать через `REPORTS_CHROMIUM_EXECUTABLE`. Лимит генераций —
`PARENT_REPORT_GENERATE_RATE` (по умолчанию `60/hour` на пользователя).

## Тесты

```bash
DJANGO_ENV=testing python manage.py test apps.reports
```

Тесты рендеринга PNG пропускаются, если Chromium не запускается.
