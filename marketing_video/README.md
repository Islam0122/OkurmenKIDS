# Обучающее видео «Кабинет маркетинга»

Ролик (~6 минут, 1920×1080, русская озвучка и субтитры) объясняет руководителям и
сотрудникам учебного центра, как устроен раздел «Маркетинг» в LMS OkurmenKIDS,
как с ним работать и чего в нём пока нет. Все экранные сцены сняты в **реальном
интерфейсе** LMS (локальный запуск на демо-данных), слайды нарисованы скриптом.

| Файл | Что это |
|---|---|
| `marketing_tutorial.mp4` | итоговое видео (H.264 + AAC, вшитые субтитры и отдельная дорожка субтитров) |
| `script.md` | полный текст озвучки с тайм-кодами |
| `storyboard.md` | раскадровка: сцены, длительность, действия на экране |
| `subtitles.srt` | субтитры с тайм-кодами |
| `scenes.py` | **единый источник** сценария: реплики, слайды, раскадровка |
| `tts.py` | офлайн-озвучка нейросетевым голосом Piper → `build/narration.wav`, `build/timing.json` |
| `record.cjs` | запись интерфейса: Playwright + CDP-скринкаст, действия привязаны к репликам |
| `compose.py` | монтаж: приближения, подписи, субтитры, переходы, кодирование |
| `docs.py` | генерирует `script.md`, `storyboard.md`, `subtitles.srt` |
| `verify.py` | проверка готового файла и контрольные кадры в `build/check/` |
| `demo/video_settings.py` | настройки Django для отдельной демо-базы SQLite |
| `demo/seed_demo.py` | обезличенные демо-данные (вымышленная команда, без контактов) |
| `build.sh` | весь конвейер одной командой |

Промежуточные файлы (`build/`) в репозиторий не входят.

## Как пересобрать

Нужны: Python 3.12+, Node 20+, FFmpeg, Chromium для Playwright. Голос Piper (~80 МБ) `tts.py` скачает сам.

```bash
# один раз
sudo apt-get install -y ffmpeg
python3 -m venv .venv && . .venv/bin/activate
pip install -r backend/requirements.txt numpy pillow piper-tts
(cd frontend && npm ci)
npm i -g playwright && npx playwright install chromium   # если Playwright ещё не установлен

# сборка (из корня репозитория)
PYTHON=.venv/bin/python ./marketing_video/build.sh
```

`build.sh` по шагам:

1. `tts.py` — синтезирует реплики, считает таймлайн; `docs.py` — обновляет сценарий, раскадровку и субтитры.
2. Создаёт отдельную демо-базу (`MARKETING_DEMO_DB`, по умолчанию `/tmp/okurmen_marketing_demo.sqlite3`)
   и заполняет её `seed_demo.py`. Скрипт отказывается работать, если имя базы не содержит `demo`.
3. Поднимает Django (`127.0.0.1:8000`) и Vite (`127.0.0.1:5173`), если они ещё не запущены.
4. `record.cjs` — входит под `demo_marketing` и проходит сцены, кадры — в `build/rec/`.
5. `compose.py` — монтаж в `marketing_tutorial.mp4` (4 параллельных процесса, ~5 минут).
6. `verify.py` — проверка.

Только перемонтаж по готовой записи: `SKIP_RECORD=1 ./marketing_video/build.sh`.
Превью отдельных кадров: `python marketing_video/compose.py --preview 75 145 290` → `build/preview/`.

Правка текста: меняйте реплики только в `scenes.py`, затем полная пересборка — длительность
реплик меняет тайминг действий в записи. Даты демо-данных считаются от сегодняшнего дня,
поэтому ролик можно пересобрать в любой день; конкретные цифры в кадре будут другими,
а озвучка их намеренно не называет.

## Безопасность и данные

* Production-база не используется: только локальная SQLite в `/tmp`, создаваемая с нуля.
* Люди в кадре вымышленные (Алина Демидова, Тимур Садыков, Мира Ким), почты — `@example.com`,
  ссылки на посты — `https://example.com/…`. Пароль демо-учётки в кадре скрыт точками и в
  субтитры/сценарий не попадает (это проверяет `verify.py`).
* Озвучка синтезирована офлайн нейросетевым голосом Piper `ru_RU-dmitri-medium`
  (модель из GitHub-релиза sherpa-onnx): облачные TTS (Microsoft, Google) в среде
  сборки недоступны. Другой голос: `TTS_VOICE=ruslan|denis|irina`, темп —
  `TTS_LENGTH_SCALE` (по умолчанию 1.12), прежний синтезатор — `TTS_ENGINE=rhvoice`
  (нужны пакеты `rhvoice rhvoice-russian`). После смены голоса нужна полная
  пересборка: меняются длительности реплик. Фоновой музыки нет — свободной
  библиотеки музыки в среде не было, добавлять неизвестные треки не стали.

## Что показано в видео — карта функциональности

Источник истины: `backend/apps/marketing`, `frontend/src/features/marketing`, `backend/docs/marketing.md`.

**Работает полностью**

| Функция | Интерфейс | API | Данные |
|---|---|---|---|
| Обзор: приветствие, 8 показателей за месяц, ближайшие задачи и публикации, листание месяцев | `/marketing` | `GET dashboard/` | `ContentItem`, `MarketingTask` |
| Контент-план: календарь и список, фильтры (канал, статус, ответственный, поиск), идеи без даты | `/marketing/content` | `content/` (CRUD) | `ContentItem` |
| Статусы публикации: идея → подготовка → согласование → запланировано → опубликовано; дата обязательна для двух последних; `published_at` ставит сервер | диалог публикации | сериализатор + ограничения БД | `ContentItem` |
| Задачи: срок, приоритет, статус, ответственный; «просрочено» вычисляется; быстрая отметка выполнения; `completed_at` ставит сервер | `/marketing/tasks` | `tasks/` (CRUD) | `MarketingTask` |
| Отчёты за неделю/месяц: выполнение плана, опубликовано, подготовлено, задачи в срок/с опозданием, динамика, по каналам, по сотрудникам | `/marketing/reports` | `GET reports/` | расчёт в `reports.py` |
| Права: роль «Маркетинг» и администратор; удалять — автор или администратор; о людях — только имя | все страницы | `IsMarketingTeam`, `can_delete` | — |
| Приход/уход через QR-код офиса (общий механизм посещаемости) | кнопка в шапке | `staff-attendance/` | `apps.staff_attendance` |
| «Моя зарплата» — только свои начисления (расчёт ведёт бухгалтерия) | `/marketing/my-salary` | `accounting/my/` | `apps.accounting` |

**Частично**

* Администратор имеет доступ к API кабинета и к Django admin, но во фронтенде маршрут `/marketing` открыт только роли `marketing`.
* У директора нет экрана маркетинга (ни в интерфейсе, ни в API — 403).

**Отсутствует (в видео названо ограничением, не показано как функция)**

* Заявки/лиды, их источники и статусы; рекламные кампании и бюджеты.
* Связь маркетинга со студентами, группами, продажами и оплатами → нет воронки, конверсии, стоимости привлечения.
  Студентов добавляют ассистенты в своём разделе, без привязки к маркетингу.
* Статистика охватов и вовлечённости из соцсетей, интеграции с площадками.
* Напоминания и уведомления о сроках задач и публикаций.
