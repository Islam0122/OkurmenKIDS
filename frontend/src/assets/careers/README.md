# Фотографии карьерного сайта

Положите сюда файлы с этими именами — страница `/careers` подхватит их при
следующей сборке (Vite добавит хеш в имя и сожмёт путь, ссылки не ломаются):

| Файл | Где на странице | Рекомендуемый кадр |
|---|---|---|
| `hero.jpg` | Первый экран, большое фото | Занятие или команда за работой, вертикальный кадр 4:5, от 1600 px по длинной стороне |
| `teaching.jpg` | Первый экран, малое фото | Тренер и ученики на занятии, 4:3 |
| `team.jpg` | «Люди и атмосфера», крупное | Команда вместе (встреча, планёрка), 3:2 |
| `classroom.jpg` | «Люди и атмосфера» | Учебный класс, рабочие места, 4:5 |
| `culture.jpg` | «Люди и атмосфера» | Общее событие команды, 4:3 |

Форматы: `.jpg`, `.jpeg`, `.webp`, `.avif`, `.png`. Сжимайте до 200–400 КБ
(например, WebP качества 75–80): страница должна быстро открываться с телефона.

Важно: используйте настоящие фотографии OKURMEN KIDS (с согласия людей в
кадре) или фото с лицензией, разрешающей коммерческое использование. Стоковые
снимки не выдавайте за сотрудников компании — подписи к фото в
`src/features/careers/photos.ts` нейтральные и описывают атмосферу, а не людей.

Пока файла нет, на его месте показывается фирменная иллюстрация — битых
изображений не бывает.
