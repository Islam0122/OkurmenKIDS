# Инструкция для тренеров Okurmen KIDS LMS

`Okurmen_KIDS_LMS_instrukciya_dlya_trenerov.pptx` — презентация-инструкция для тренеров академии по работе с личным кабинетом.

## Источник материала

- Карта функций составлена по коду фронтенда (`frontend/src/app/router`, `frontend/src/components/layout/navItems.ts`) — только то, что реально доступно роли `teacher`.
- Скриншоты сделаны в браузере (Playwright) на локальном dev-стенде, поднятом из этого же репозитория и засеянном командой `manage.py seed_demo_data` (демо-тренер `islam_it`), а не на продакшн-окружении — чтобы не логиниться в боевую систему без явного разрешения.
- Интерфейс идентичен продакшену (`okurmen-kids-drab.vercel.app`), так как использован тот же код фронтенда.

## Что уточнить у команды разработки

Отмечено в последнем слайде презентации:

- Учебные материалы к занятиям (файлы, презентации, ссылки) — в интерфейсе не найдены.
- Push- или email-уведомления — подтверждён только раздел «Новости» с колокольчиком (счётчик непрочитанного).
- Отдельная карточка студента с полной историей (`/app/students/:id`) существует в коде, но не была подробно проверена по содержимому.
