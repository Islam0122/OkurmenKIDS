# Демо-видео «OkurmenKIDS — Monthly Reports Generator»

`scripts/demo_reports.py` записывает ~60-секундное видео реальной работы функции
«Отчёты для родителей». Используются настоящий React-фронтенд, настоящий Django-бэкенд
и Playwright. Отчёт генерирует бэкенд прямо во время записи, ничего не подменяется. Поверх
интерфейса скрипт рисует только оформление: указатель мыши, подписи, титры и увеличенный
просмотр готового PNG.

Результат лежит в `videos/`:

| Файл | |
|---|---|
| `okurmenkids_reports_demo.mp4` | видео 1920×1080, H.264 |
| `okurmenkids_reports_demo.webm` | то же, VP9 |
| `okurmenkids_report_final.png` | итоговый отчёт: PNG, скачанный кнопкой «Скачать PNG» во время записи |

## Сцены

| Время | Сцена |
|---|---|
| 0–5 с | Титр «Monthly Reports Generator» → главная тренера → «Мои группы» |
| 5–12 с | Группа → вкладка KPI → «Прошлый месяц» → статистика студентов |
| 12–21 с | KPI → «Отчёты» → «Создать отчёт»: группа, месяц, язык, «Изображение и текст» |
| 21–30 с | Предпросмотр: посещаемость, ДЗ, баллы, тесты, статусы и рекомендации (локальный Python), затем «Сгенерировать отчёт» |
| 30–42 с | Готовый PNG: брендинг, статистика группы, таблица, прогресс-бары, статусы, рекомендации (с увеличением) |
| 42–50 с | Текст для WhatsApp: переключение RU ↔ KY, правка текста, «Скопировать текст» |
| 50–60 с | «Скачать PNG» → история отчётов → предыдущий отчёт → финальный титр |

## 1. Демо-данные

Команда `seed_reports_demo` создаёт тренера `demo_trainer` и группу «PY-KIDS-07» с
12 **вымышленными** студентами. Телефонов и других личных данных нет. Добавляются
занятия, посещаемость, ДЗ, оценки и тесты за текущий и два предыдущих месяца. Повторный
запуск заменяет только собственные демо-данные. В production команда не запускается.

```bash
cd backend
export REPORTS_DEMO_PASSWORD='придумайте-пароль'
python manage.py migrate
python manage.py seed_reports_demo
```

Без `REPORTS_DEMO_PASSWORD` команда сама сгенерирует пароль и выведет его один раз.

## 2. Запуск приложения

```bash
cd backend && python manage.py runserver 127.0.0.1:8000
```

```bash
cd frontend && npm install && npm run dev -- --port 5173 --host 127.0.0.1
```

Для PNG бэкенду нужен Chromium: `python -m playwright install --with-deps chromium`
(подробности — в `backend/docs/parent_reports.md`).

## 3. Запись

```bash
pip install playwright
python -m playwright install chromium
export REPORTS_DEMO_PASSWORD='тот же пароль'
python scripts/demo_reports.py
```

Сначала скрипт проверяет функцию через API. На первой же ошибке запись не начинается,
скрипт пишет, что именно не работает:

* фронтенд и бэкенд отвечают, вход тренера выполняется;
* демо-группа доступна;
* отчёт генерируется, статистика посчитана;
* PNG скачивается;
* текст для WhatsApp сформирован, переключение RU → KY работает;
* индивидуальные отчёты (KY) генерируются. Эти отчёты потом видны в истории.

Во время записи скрипт тоже проверяет каждый шаг: появление предпросмотра, PNG, смену
языка текста, тост «Текст скопирован», скачанный PNG.

Пароль берётся только из переменной окружения. Браузер получает JWT-токены через
localStorage, форма входа не заполняется, поэтому на видео нет ни паролей, ни токенов.

Переменные окружения:

| Переменная | По умолчанию |
|---|---|
| `REPORTS_DEMO_PASSWORD` | обязательна |
| `REPORTS_DEMO_USERNAME` | `demo_trainer` |
| `DEMO_FRONTEND_URL` | `http://127.0.0.1:5173` |
| `DEMO_API_URL` | `http://127.0.0.1:8000/api/v1` |
| `DEMO_GROUP_NAME` | `PY-KIDS-07` |
| `DEMO_OUTPUT_DIR` | `videos/` |
| `DEMO_HEADED` | `1`, чтобы видеть окно браузера |

Перед повторной записью стоит снова запустить `seed_reports_demo`: история отчётов
очистится, и на видео будут только отчёты этой записи.

## FFmpeg

Если `ffmpeg` установлен, скрипт обрезает пустые кадры в начале и сохраняет MP4 и WebM.
Без него сохраняется исходный WebM от Playwright. Сконвертировать его можно так:

```bash
ffmpeg -i videos/okurmenkids_reports_demo.webm -c:v libx264 -pix_fmt yuv420p -crf 22 -movflags +faststart videos/okurmenkids_reports_demo.mp4
```

## Если Playwright не находит браузер

Версия Python-пакета `playwright` должна совпадать с установленным браузером. Обычно
это обеспечивает `python -m playwright install chromium`. Если браузер уже установлен
другой версией Playwright, поставьте ту же версию пакета в отдельное окружение,
например `pip install playwright==1.63.0`.
