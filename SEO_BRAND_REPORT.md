## B. Метаданные

* **Уникальные Title и Description:** все 10 статических страниц × 3 языка = **30**. Title 50–60 символов, Description 140–160, все уникальны (это проверяется тестом). Ключевые слова: IT-курсы для детей, Бишкек, Python, веб, React, игры; на кыргызском — «балдар үчүн IT курстары», «программалоо».
* **Детальные страницы** (курсы, проекты, новости, события, достижения, команда) строятся из данных самого материала: `<название> — <раздел на языке страницы> | OKURMEN KIDS`, не длиннее 70 символов. Если в CMS заполнено `seo_title`/`seo_description`, используется оно. Короткое описание дополняется фактической фразой о разделе, у проектов — реальным списком технологий. **0 дубликатов Title и 0 дубликатов Description на 80 индексируемых URL.** Пример: два разных проекта «ShopVerce» теперь различаются по описанию.
* **Canonical:** на каждой странице свой, `https://www.okurmenkids.com/…`, без слэша в конце и в нижнем регистре. Он не зависит от текущего хоста, поэтому копии на `*.vercel.app` указывают на основной сайт.
* **hreflang:** для статических страниц ru, ky, en и x-default (→ ru). Новости и проекты существуют только на русском (в backend нет полей перевода), поэтому у их `/ky` и `/en` копий canonical указывает на русский URL, а hreflang нет. Для курсов, событий, достижений и команды язык попадает в hreflang, только если материал действительно переведён: API подставляет русский текст на место отсутствующего перевода, поэтому версии сравниваются с русской. Сейчас достижение «Футбольный турнир…» не переведено, остальные материалы переведены.
* `<html lang>` соответствует языку страницы и в собранном HTML, и после переключения языка.

## E. Google Search Console

**Что сделать владельцу после деплоя** (паролей не нужно, только вход в свой аккаунт Google):
1. Search Console → ресурс `okurmenkids.com` (Domain) → **Файлы Sitemap**: удалить старый `https://okurmenkids.com/sitemap.xml`, если он там есть, и отправить `https://www.okurmenkids.com/sitemap.xml`. Статус должен стать «Успешно», обнаружено около 80 URL.
2. **Проверка URL** для каждого: `https://www.okurmenkids.com/`, `/courses`, `/projects`, `/news`, `/events`, `/about`, `/ky`, `/courses/premium`. Затем «Проверить страницу на сайте» → убедиться, что «Канонический URL, выбранный Google» = указанный → «Запросить индексирование».
3. **Индексирование → Страницы**: записать базовые цифры. Ожидайте, что `/ky/news/*`, `/en/news/*`, `/ky/projects/*` и `/en/projects/*` уйдут в «Страница является копией, канонический вариант выбран пользователем». Это и задумано.
4. **Core Web Vitals** (мобильные) и **HTTPS**: записать статус. Полевые данные появятся через 28 дней трафика.
5. Rich Results Test (https://search.google.com/test/rich-results) для `/`, `/courses/premium` и любой новости: ожидается 0 ошибок для Organization, Breadcrumb и Article.
6. Повторить шаг 2 для `https://lms.okurmenkids.com/news`. Если адрес проиндексирован, см. F1.
